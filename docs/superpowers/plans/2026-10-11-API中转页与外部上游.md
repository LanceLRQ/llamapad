# API 中转页与外部上游 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 新增「API 中转」页面展示接入信息与托管模型的系统级卡片，并让面板能中转用户登记的外部 OpenAI 兼容服务（外部上游），外部上游可设为默认模型。

**架构：** 新增一层纯逻辑「路由表」，把运行中的托管模型与启用的外部上游合成候选目标，中转 handler 只认这张表；`RuntimeService`、指标采集、排空、就绪探测都不改。外部上游存 SQLite 新表，存活状态是进程内状态机，可达时定时探测、不可达时停止探测并由请求激活。

**技术栈：** Next.js App Router route handlers、better-sqlite3、zod、next-intl、shadcn/ui、Vitest（`environment: node`，只测纯逻辑与服务端模块）。

**规格：** `docs/_internal/features/2026-10-11-API中转页与外部上游-design.md`（该目录不入库，执行前确认文件存在；计划与规格冲突时以规格为准，本计划「与规格的差异」一节列出的三处除外）。

## 全局约束

- 包管理器是 pnpm。验收命令：`pnpm test`、`pnpm run lint`、`pnpm exec tsc --noEmit`、`pnpm run build`。
- 动手写任何 route handler 或页面之前，先读 `node_modules/next/dist/docs/` 中对应指南（本仓库的 Next 版本与常见用法有差异，以该目录为准）。
- 组件不写单测（未装 jsdom）。可测判定一律下沉到 `src/lib/*.ts`，测试文件与实现同目录并列。
- 文案中英对称：`src/i18n/messages/zh.json` 与 `en.json` 的键必须一一对应。
- 上游名规则：`^[a-z0-9][a-z0-9-]*$`；保留名 `test`、`probe`。
- 地址只接受 `http:` / `https:`，不做内网拦截。
- 存活状态参数：探测间隔 15 秒、探测超时 3 秒、连续 3 次失败转不可达、请求激活限频 15 秒。
- 外部上游不做 `reasoning_effort` 改写、不进 YAML 导出、不进指标采集、Playground 不支持。
- 密钥明文只存库与用于转发，任何接口响应都不返回明文，只返回尾 4 位。
- 命名禁用 optimize / fix / improved 等词；不写版本标识注释；不加 Co-Authored-By。
- Git：在分支 `feat/relay-upstreams` 上工作；`git add` 与 `git commit` 分两条命令执行；不执行 `git push`。
- 没有外部上游时，中转的每一条现有路径行为必须不变（回归底线）。

## 与规格的差异

1. **时间列类型**：`upstreams.created_at` / `updated_at` 用 INTEGER 毫秒（与 `models`、`param_presets` 表一致），接口响应里转 ISO 字符串。规格写的是 TEXT。
2. **中转地址的 origin**：由服务端从请求头（`x-forwarded-proto` / `x-forwarded-host` / `host`）推导，不在客户端读 `window.location`，避免水合不一致。经反代访问时结果与浏览器地址一致。
3. **模型页的「默认」标记**：设置了启用的默认上游后，模型页上所有托管模型都不显示「默认」标记（即使上游暂时不可达、流量被降级到某个托管模型）。降级状态只在中转页展示。

```ts
import { LLAMA_PROXY_ALIAS, LLAMA_PROXY_ROUTE } from "./proxy-alias";

/**
 * API 中转页「接入信息」的纯逻辑：对外地址怎么拼、示例怎么写。
 *
 * origin 由服务端从请求头推导而不是在客户端读 window.location：页面是服务端渲染的，
 * 客户端再读一次会让首帧与水合后的地址不一致。经反代访问时 x-forwarded-* 给出的
 * 就是浏览器地址栏里的那个。
 */

/** 逗号分隔的多值头取第一个（多级反代会追加） */
function first(value: string | null): string | null {
  const head = value?.split(",")[0]?.trim() ?? "";
  return head === "" ? null : head;
}

export function originFromHeaders(get: (name: string) => string | null): string {
  const host = first(get("x-forwarded-host")) ?? first(get("host"));
  if (host === null) return "";
  const proto = first(get("x-forwarded-proto")) ?? "http";
  return `${proto}://${host}`;
}

export interface RelayBaseUrls {
  /** 短地址（/llama-proxy 别名） */
  short: string;
  /** 长地址（真实路由） */
  long: string;
}

/** OpenAI 兼容客户端要填的 base URL：到 /v1 为止 */
export function relayBaseUrls(origin: string): RelayBaseUrls {
  const base = origin.replace(/\/+$/, "");
  return { short: `${base}${LLAMA_PROXY_ALIAS}/v1`, long: `${base}${LLAMA_PROXY_ROUTE}/v1` };
}

/** 没有默认模型时示例里用的占位名 */
export const SNIPPET_PLACEHOLDER_MODEL = "your-model";

export function buildCurlSnippet(baseUrl: string, model: string | null): string {
  const body = JSON.stringify({
    model: model ?? SNIPPET_PLACEHOLDER_MODEL,
    messages: [{ role: "user", content: "Hello" }],
  });
  return [
    `curl ${baseUrl}/chat/completions \\`,
    `  -H "Authorization: Bearer lp_xxxxxxxx" \\`,
    `  -H "Content-Type: application/json" \\`,
    `  -d '${body}'`,
  ].join("\n");
}

/** 启动时间的展示文本。固定用 UTC：服务端与浏览器时区不同，本地化会造成水合不一致 */
export function formatStartedAt(iso: string | null): string | null {
  if (iso === null) return null;
  const ms = Date.parse(iso);
  if (Number.isNaN(ms)) return null;
  return `${new Date(ms).toISOString().slice(0, 19).replace("T", " ")} UTC`;
}
```

`src/server/relayOverview.ts`：

```ts
import type Database from "better-sqlite3";
import { mergeConfig } from "../core/config";
import { llamaUpstreamBase } from "./llamaProxy";
import { decorateRuntimeStatus, type RunningModelView } from "./modelsView";
import { createModelRepo } from "./repo/models";
import type { RuntimeService } from "./runtime";

/**
 * API 中转页「托管服务」卡片的数据装配：在运行状态视图上补两样东西——面板实际
 * 访问该模型用的上游地址，以及合并后生效的关键参数。只读，不触发任何探测以外的 IO。
 */

/** 卡片上展示的关键参数（合并 default 与模型 overrides 之后的生效值） */
export interface ManagedServiceParams {
  image: string;
  gpu: string;
  ctxSize: number;
  gpuLayers: number;
  reasoningEffort: string;
  effortRounding: string;
  /** 思考强度别名表的条目数；明细在模型编辑页看 */
  effortAliasCount: number;
  specType: string;
}

export interface ManagedServiceView extends RunningModelView {
  isDefault: boolean;
  /** 面板侧访问该模型的地址；端口未知时为 null */
  upstreamBase: string | null;
  /** 模型行已删时为 null */
  params: ManagedServiceParams | null;
}

export interface RelayOverview {
  defaultModel: string | null;
  services: ManagedServiceView[];
}

export async function buildRelayOverview(
  db: Database.Database,
  runtime: RuntimeService,
  probe?: (hostPort: number) => Promise<boolean>,
): Promise<RelayOverview> {
  const status = await decorateRuntimeStatus(db, runtime, probe);
  const repo = createModelRepo(db);
  const defaults = repo.getDefaultConfig();

  const services = status.models.map((entry): ManagedServiceView => {
    const row = repo.getModel(entry.model);
    const merged = row ? mergeConfig(defaults, row.overrides ?? {}) : null;
    return {
      ...entry,
      isDefault: status.defaultModel === entry.model,
      upstreamBase: entry.hostPort !== null ? llamaUpstreamBase(entry.hostPort) : null,
      params: merged
        ? {
            image: merged.docker.image,
            gpu: merged.docker.gpu,
            ctxSize: merged.server.ctx_size,
            gpuLayers: merged.server.gpu_layers,
            reasoningEffort: merged.server.reasoning_effort,
            effortRounding: merged.api.effort_rounding,
            effortAliasCount: Object.keys(merged.api.effort_aliases).length,
            specType: merged.server.spec_type,
          }
        : null,
    };
  });

  return { defaultModel: status.defaultModel, services };
}
```

```ts
import { NextResponse } from "next/server";
import { requireAuth } from "@/server/auth";
import { getDb } from "@/server/db";
import { getRuntimeService } from "@/server/locators";

export const runtime = "nodejs";

/**
```

```ts
/**
 * 外部上游的输入规范化（纯函数）：地址、名字、密钥尾号。
 *
 * 地址存的是「到 /v1 之前」的根：中转把客户端路径（/v1/chat/completions 等）原样
 * 拼在后面，用户照着 OpenAI 客户端的习惯把 /v1 也填进来时在这里去掉，否则会拼出
 * /v1/v1/…。不拦内网地址——登记者是已登录的管理员，访问内网服务正是这个功能的用途。
 */

export type UpstreamUrlResult = { ok: true; url: string } | { ok: false; reason: "invalid" | "protocol" };

export function normalizeUpstreamBaseUrl(raw: string): UpstreamUrlResult {
  let parsed: URL;
  try {
    parsed = new URL(raw.trim());
  } catch {
    return { ok: false, reason: "invalid" };
  }
  if (parsed.protocol !== "http:" && parsed.protocol !== "https:") return { ok: false, reason: "protocol" };

  let path = parsed.pathname.replace(/\/+$/, "");
  if (path.toLowerCase().endsWith("/v1")) path = path.slice(0, -3).replace(/\/+$/, "");
  // 用 host 而非 href 重组：顺带丢掉地址里的用户名密码、query 与 hash
  return { ok: true, url: `${parsed.protocol}//${parsed.host}${path}` };
}

/** 与托管模型同一条命名规则（core/schemas.ts 的 modelSchema.name） */
const NAME_PATTERN = /^[a-z0-9][a-z0-9-]*$/;

/** 与 /api/v1/upstreams 下的静态路径段冲突的名字 */
const RESERVED_NAMES = new Set(["test", "probe"]);

export function upstreamNameProblem(name: string): "format" | "reserved" | null {
  if (!NAME_PATTERN.test(name)) return "format";
  if (RESERVED_NAMES.has(name)) return "reserved";
  return null;
}

/** 密钥的可辨识尾号：明文不出库，界面只展示这个 */
export function keyTail(key: string | null): string | null {
  if (key === null || key === "") return null;
  return key.slice(-4);
}
```

```ts
import type Database from "better-sqlite3";

import { normalizeUpstreamBaseUrl, upstreamNameProblem } from "../../lib/upstream-url";

/**
 * 外部上游仓储：不由面板启停的 OpenAI 兼容服务的登记表。
 *
 * name 是中转请求里的 model 值，与托管模型共用一个命名空间，写入时在这里检查
 * models 表（另一个方向的检查在 repo/models.ts 的 createModel）。name 不支持修改：
 * 它是主键，也是客户端写死的模型名，要换名字就删除重建。
 *
 * 本模块返回的 StoredUpstream 带明文 apiKey，只在服务端内部流转；出接口前必须
 * 经 server/upstreams/view.ts 的 toUpstreamView 转成不含明文的视图。
 */

/** settings 表里默认上游的键 */
const DEFAULT_UPSTREAM_KEY = "default_upstream";

export type UpstreamErrorCode = "INVALID" | "NOT_FOUND" | "CONFLICT";

export class UpstreamError extends Error {
  constructor(
    readonly code: UpstreamErrorCode,
    message: string,
    /** INVALID 时指出是哪个字段，接口据此给出字段级提示 */
    readonly field?: string,
  ) {
    super(message);
    this.name = "UpstreamError";
  }
}

export function upstreamErrorStatus(code: UpstreamErrorCode): number {
  if (code === "NOT_FOUND") return 404;
  if (code === "CONFLICT") return 409;
  return 400;
}

export interface StoredUpstream {
  name: string;
  displayName: string;
  baseUrl: string;
  apiKey: string | null;
  upstreamModel: string | null;
  enabled: boolean;
  note: string | null;
  createdAt: number;
  updatedAt: number;
}

export interface CreateUpstreamArgs {
  name: string;
  displayName: string;
  baseUrl: string;
  apiKey?: string | null;
  upstreamModel?: string | null;
  enabled?: boolean;
  note?: string | null;
}

/** 字段缺席（undefined）= 不改。apiKey 传空串或 null = 清除 */
export interface UpdateUpstreamArgs {
  displayName?: string;
  baseUrl?: string;
  apiKey?: string | null;
  upstreamModel?: string | null;
  enabled?: boolean;
  note?: string | null;
}

interface Row {
  name: string;
  display_name: string;
  base_url: string;
  api_key: string | null;
  upstream_model: string | null;
  enabled: number;
  note: string | null;
  created_at: number;
  updated_at: number;
}

function toStored(row: Row): StoredUpstream {
  return {
    name: row.name,
    displayName: row.display_name,
    baseUrl: row.base_url,
    apiKey: row.api_key,
    upstreamModel: row.upstream_model,
    enabled: row.enabled === 1,
    note: row.note,
    createdAt: row.created_at,
    updatedAt: row.updated_at,
  };
}

/** 可选文本字段：去首尾空白，空串归 null */
function optionalText(value: string | null | undefined): string | null {
  const trimmed = value?.trim() ?? "";
  return trimmed === "" ? null : trimmed;
}

function requireDisplayName(raw: string): string {
  const value = raw.trim();
  if (value === "") throw new UpstreamError("INVALID", "INVALID: 展示名不能为空", "displayName");
  return value;
}

function requireBaseUrl(raw: string): string {
  const result = normalizeUpstreamBaseUrl(raw);
  if (!result.ok) {
    const detail = result.reason === "protocol" ? "只支持 http 或 https" : "不是合法的地址";
    throw new UpstreamError("INVALID", `INVALID: 上游地址${detail}`, "baseUrl");
  }
  return result.url;
}

export function listUpstreams(db: Database.Database): StoredUpstream[] {
  return (db.prepare("SELECT * FROM upstreams ORDER BY name").all() as Row[]).map(toStored);
}

export function getUpstream(db: Database.Database, name: string): StoredUpstream | null {
  const row = db.prepare("SELECT * FROM upstreams WHERE name = ?").get(name) as Row | undefined;
  return row === undefined ? null : toStored(row);
}

export function createUpstream(db: Database.Database, args: CreateUpstreamArgs): StoredUpstream {
  const problem = upstreamNameProblem(args.name);
  if (problem === "format") {
    throw new UpstreamError("INVALID", "INVALID: 名字只允许小写字母、数字与连字符，且不能以连字符开头", "name");
  }
  if (problem === "reserved") throw new UpstreamError("INVALID", `INVALID: ${args.name} 是保留名`, "name");
  const displayName = requireDisplayName(args.displayName);
  const baseUrl = requireBaseUrl(args.baseUrl);

  if (db.prepare("SELECT 1 FROM models WHERE name = ?").get(args.name) !== undefined) {
    throw new UpstreamError("CONFLICT", `CONFLICT: 已有同名的模型配置: ${args.name}`, "name");
  }
  if (getUpstream(db, args.name) !== null) {
    throw new UpstreamError("CONFLICT", `CONFLICT: 上游已存在: ${args.name}`, "name");
  }

  const now = Date.now();
  db.prepare(
    `INSERT INTO upstreams(name, display_name, base_url, api_key, upstream_model, enabled, note, created_at, updated_at)
     VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)`,
  ).run(
    args.name,
    displayName,
    baseUrl,
    optionalText(args.apiKey),
    optionalText(args.upstreamModel),
    args.enabled === false ? 0 : 1,
    optionalText(args.note),
    now,
    now,
  );
  return getUpstream(db, args.name)!;
}

export function updateUpstream(db: Database.Database, name: string, args: UpdateUpstreamArgs): StoredUpstream {
  const current = getUpstream(db, name);
  if (current === null) throw new UpstreamError("NOT_FOUND", `NOT_FOUND: 上游不存在: ${name}`);

  const next = {
    displayName: args.displayName === undefined ? current.displayName : requireDisplayName(args.displayName),
    baseUrl: args.baseUrl === undefined ? current.baseUrl : requireBaseUrl(args.baseUrl),
    apiKey: args.apiKey === undefined ? current.apiKey : optionalText(args.apiKey),
    upstreamModel: args.upstreamModel === undefined ? current.upstreamModel : optionalText(args.upstreamModel),
    enabled: args.enabled === undefined ? current.enabled : args.enabled,
    note: args.note === undefined ? current.note : optionalText(args.note),
  };

  db.prepare(
    `UPDATE upstreams
     SET display_name = ?, base_url = ?, api_key = ?, upstream_model = ?, enabled = ?, note = ?, updated_at = ?
     WHERE name = ?`,
  ).run(next.displayName, next.baseUrl, next.apiKey, next.upstreamModel, next.enabled ? 1 : 0, next.note, Date.now(), name);
  return getUpstream(db, name)!;
}

export function deleteUpstream(db: Database.Database, name: string): void {
  const info = db.prepare("DELETE FROM upstreams WHERE name = ?").run(name);
  if (info.changes === 0) throw new UpstreamError("NOT_FOUND", `NOT_FOUND: 上游不存在: ${name}`);
  db.prepare("DELETE FROM settings WHERE key = ? AND value = ?").run(DEFAULT_UPSTREAM_KEY, name);
}

/**
 * 读默认上游名。指向的上游已不存在（手工改库等脏数据）时当作未设置并顺手删掉该键，
 * 免得每次决议都带着一条无效记录。停用的上游仍然返回——停用只是暂时让出默认，
 * 重新启用后要恢复，是否生效由路由决议判断。
 */
export function getDefaultUpstream(db: Database.Database): string | null {
  const row = db.prepare("SELECT value FROM settings WHERE key = ?").get(DEFAULT_UPSTREAM_KEY) as
    | { value: string }
    | undefined;
  if (row === undefined) return null;
  if (getUpstream(db, row.value) === null) {
    clearDefaultUpstream(db);
    return null;
  }
  return row.value;
}

export function setDefaultUpstream(db: Database.Database, name: string): void {
  if (getUpstream(db, name) === null) throw new UpstreamError("NOT_FOUND", `NOT_FOUND: 上游不存在: ${name}`);
  db.prepare(
    "INSERT INTO settings(key, value) VALUES (?, ?) ON CONFLICT(key) DO UPDATE SET value = excluded.value",
  ).run(DEFAULT_UPSTREAM_KEY, name);
}

export function clearDefaultUpstream(db: Database.Database): void {
  db.prepare("DELETE FROM settings WHERE key = ?").run(DEFAULT_UPSTREAM_KEY);
}

/**
 * 「默认上游已设置且处于启用状态」时返回它的名字，否则 null。只看库，不看存活状态：
 * 模型页据此决定要不要给托管模型显示「默认」标记（见 modelsView.ts）。
 */
export function getActiveDefaultUpstream(db: Database.Database): string | null {
  const name = getDefaultUpstream(db);
  if (name === null) return null;
  return getUpstream(db, name)?.enabled ? name : null;
}
```

```ts
/**
 * 外部上游存活状态机（纯函数）。
 *
 * 「成功」的口径是拿到了 HTTP 响应，不论状态码：上游回 401 / 404 / 500 说明服务在线，
 * 密钥或路径问题不该让它被判为不可达。只有网络层失败与超时算失败。
 *
 * 不可达后停止定时探测是有意的：外部上游可能长时间离线，对着一个死地址每 15 秒
 * 请求一次没有意义。恢复靠请求激活（见 server/upstreams/monitor.ts）。
 */

export type UpstreamHealthState = "unknown" | "reachable" | "unreachable";

export interface UpstreamHealth {
  state: UpstreamHealthState;
  /** 连续失败次数；成功即清零 */
  failures: number;
  /** 最近一次探测或转发得出结论的时间（毫秒）；从未有过为 null */
  lastCheckedAt: number | null;
  /** 最近一次失败的原因；最近一次是成功则为 null */
  lastError: string | null;
  /** 最近一次由请求激活探测的时间（限频用） */
  lastActivatedAt: number | null;
}

/** 连续失败多少次转为不可达 */
export const FAILURE_THRESHOLD = 3;
/** 定时探测间隔，也是请求激活的限频窗口 */
export const PROBE_INTERVAL_MS = 15_000;
/** 单次探测超时 */
export const PROBE_TIMEOUT_MS = 3_000;

export const INITIAL_HEALTH: UpstreamHealth = {
  state: "unknown",
  failures: 0,
  lastCheckedAt: null,
  lastError: null,
  lastActivatedAt: null,
};

export type ProbeOutcome = { ok: true } | { ok: false; error: string };

export function applyOutcome(health: UpstreamHealth, outcome: ProbeOutcome, now: number): UpstreamHealth {
  if (outcome.ok) {
    return { ...health, state: "reachable", failures: 0, lastCheckedAt: now, lastError: null };
  }
  const failures = health.failures + 1;
  return {
    ...health,
    state: failures >= FAILURE_THRESHOLD ? "unreachable" : health.state,
    failures,
    lastCheckedAt: now,
    lastError: outcome.error,
  };
}

/** 值得写进事件表的状态变化：进入不可达、从不可达恢复。unknown → reachable 不算 */
export function transitionOf(before: UpstreamHealth, after: UpstreamHealth): "unreachable" | "recovered" | null {
  if (before.state !== "unreachable" && after.state === "unreachable") return "unreachable";
  if (before.state === "unreachable" && after.state === "reachable") return "recovered";
  return null;
}

/** 是否参与定时探测 */
export function shouldPoll(state: UpstreamHealthState): boolean {
  return state !== "unreachable";
}

/** 路由上是否当作可用。unknown（面板刚启动还没探测过）按可用处理，不让重启造成一轮误降级 */
export function isRoutable(state: UpstreamHealthState): boolean {
  return state !== "unreachable";
}

export function canActivate(health: UpstreamHealth, now: number): boolean {
  return health.lastActivatedAt === null || now - health.lastActivatedAt >= PROBE_INTERVAL_MS;
}

export function markActivated(health: UpstreamHealth, now: number): UpstreamHealth {
  return { ...health, lastActivatedAt: now };
}
```

```ts
import {
  INITIAL_HEALTH,
  PROBE_INTERVAL_MS,
  PROBE_TIMEOUT_MS,
  applyOutcome,
  canActivate,
  markActivated,
  shouldPoll,
  transitionOf,
  type ProbeOutcome,
  type UpstreamHealth,
} from "../../lib/upstream-health";

/**
 * 外部上游的探测与调度（进程内单例，经 locators.getUpstreamMonitor 取用）。
 *
 * 状态机在 lib/upstream-health.ts，这里只负责「什么时候探测」与发请求：
 * - 可达 / 未知：每 PROBE_INTERVAL_MS 探测一次
 * - 不可达：不再定时探测，由 activate（降级请求 / 打开中转页）或 probeNow（测试连接）触发
 * - 点名转发的结果经 report 直接进状态机，不另发探测
 *
 * 状态只在内存里，面板重启后全部回到 unknown。
 */

export interface MonitorTarget {
  name: string;
  baseUrl: string;
  apiKey: string | null;
}

export interface ProbeResult {
  /** 是否拿到了 HTTP 响应（不论状态码） */
  ok: boolean;
  /** 上游的 HTTP 状态码；网络层失败为 null */
  status: number | null;
  latencyMs: number;
  /** 上游 /v1/models 返回的模型 id；非 200 或解析不了为空数组 */
  models: string[];
  error: string | null;
}

export type FetchLike = (url: string, init?: RequestInit) => Promise<Response>;

function modelIdsOf(json: unknown): string[] {
  if (typeof json !== "object" || json === null) return [];
  const data = (json as { data?: unknown }).data;
  if (!Array.isArray(data)) return [];
  return data
    .map((item) => (typeof item === "object" && item !== null ? (item as { id?: unknown }).id : undefined))
    .filter((id): id is string => typeof id === "string" && id !== "");
}

/** 探测一次：GET <baseUrl>/v1/models。不改任何状态，monitor 与「保存前测试」共用 */
export async function probeUpstream(
  target: Pick<MonitorTarget, "baseUrl" | "apiKey">,
  fetchImpl: FetchLike = fetch,
): Promise<ProbeResult> {
  const startedAt = Date.now();
  const headers = new Headers({ accept: "application/json" });
  if (target.apiKey !== null) headers.set("authorization", `Bearer ${target.apiKey}`);

  let response: Response;
  try {
    response = await fetchImpl(`${target.baseUrl}/v1/models`, {
      headers,
      signal: AbortSignal.timeout(PROBE_TIMEOUT_MS),
    });
  } catch (error) {
    return {
      ok: false,
      status: null,
      latencyMs: Date.now() - startedAt,
      models: [],
      error: error instanceof Error ? error.message : String(error),
    };
  }

  const json: unknown = response.ok ? await response.json().catch(() => null) : null;
  return {
    ok: true,
    status: response.status,
    latencyMs: Date.now() - startedAt,
    models: modelIdsOf(json),
    error: null,
  };
}

export interface UpstreamMonitorDeps {
  /** 当前启用的上游（每次调用都重新取，停用与删除即时生效） */
  listEnabled: () => MonitorTarget[];
  fetch?: FetchLike;
  now?: () => number;
  /** 进入不可达 / 从不可达恢复时回调一次（写事件表用）；抛错不影响探测 */
  onTransition?: (name: string, to: "unreachable" | "recovered") => void;
}

export interface UpstreamMonitor {
  /** 开始定时探测；幂等 */
  start(): void;
  stop(): void;
  /** 某个上游当前的状态；没探测过返回初始状态（unknown） */
  snapshot(name: string): UpstreamHealth;
  /** 把一次转发的连接结果喂给状态机 */
  report(name: string, ok: boolean, error?: string): void;
  /** 由请求激活一次后台探测（限频）；不等待结果 */
  activate(name: string): void;
  /** 立即探测并更新状态；上游未登记或已停用返回 null */
  probeNow(name: string): Promise<ProbeResult | null>;
}

export function createUpstreamMonitor(deps: UpstreamMonitorDeps): UpstreamMonitor {
  const fetchImpl = deps.fetch ?? fetch;
  const now = deps.now ?? Date.now;
  const health = new Map<string, UpstreamHealth>();
  /** 正在探测中的上游：定时轮次与请求激活可能撞在一起，同一时刻只发一个 */
  const inFlight = new Set<string>();
  let timer: ReturnType<typeof setInterval> | null = null;

  function snapshot(name: string): UpstreamHealth {
    return health.get(name) ?? INITIAL_HEALTH;
  }

  function apply(name: string, outcome: ProbeOutcome): void {
    const before = snapshot(name);
    const after = applyOutcome(before, outcome, now());
    health.set(name, after);
    const transition = transitionOf(before, after);
    if (transition !== null) {
      try {
        deps.onTransition?.(name, transition);
      } catch {
        // 事件记录失败不该连累探测本身
      }
    }
  }

  async function probe(target: MonitorTarget): Promise<ProbeResult> {
    const result = await probeUpstream(target, fetchImpl);
    apply(target.name, result.ok ? { ok: true } : { ok: false, error: result.error ?? "unknown" });
    return result;
  }

  async function probeOnce(target: MonitorTarget): Promise<void> {
    if (inFlight.has(target.name)) return;
    inFlight.add(target.name);
    try {
      await probe(target);
    } finally {
      inFlight.delete(target.name);
    }
  }

  function tick(): void {
    const targets = deps.listEnabled();
    const enabled = new Set(targets.map((t) => t.name));
    for (const name of health.keys()) {
      if (!enabled.has(name)) health.delete(name);
    }
    for (const target of targets) {
      if (shouldPoll(snapshot(target.name).state)) void probeOnce(target);
    }
  }

  return {
    start() {
      if (timer !== null) return;
      timer = setInterval(tick, PROBE_INTERVAL_MS);
      // 不让这个定时器拖住进程退出（测试与 next build 的收尾都依赖这一点）
      timer.unref?.();
    },
    stop() {
      if (timer === null) return;
      clearInterval(timer);
      timer = null;
    },
    snapshot,
    report(name, ok, error) {
      apply(name, ok ? { ok: true } : { ok: false, error: error ?? "unknown" });
    },
    activate(name) {
      const target = deps.listEnabled().find((t) => t.name === name);
      if (target === undefined) return;
      const current = snapshot(name);
      if (!canActivate(current, now())) return;
      health.set(name, markActivated(current, now()));
      void probeOnce(target);
    },
    async probeNow(name) {
      const target = deps.listEnabled().find((t) => t.name === name);
      if (target === undefined) return null;
      return probe(target);
    },
  };
}
```

```ts
/**
 * API 中转的路由表（纯函数）：把运行中的托管模型与启用的外部上游合成候选目标，
 * 决定一次请求发往谁。取代 lib/model-route.ts 里只认托管模型的 decideModelRoute。
 *
 * 点名规则沿用多模型并行时定下的原则（决策 D6）：点了名就发往它，发不了就明确报错，
 * 绝不静默改发——那会让用户以为在和 A 对话，实际回答来自 B。外部上游同理：点名一个
 * 不可达的上游照样发过去，让客户端看到真实的连接错误。
 *
 * 只有「没点名」或「点的名字面板不认识」的请求才走默认。默认上游不可达时降级到
 * 托管模型，是这张表里唯一会自动换目标的地方，并用 via: fallback-unreachable 标出来。
 */

export interface RelayUpstream {
  name: string;
  enabled: boolean;
  /** 存活状态是否允许作为默认目标（unknown 与 reachable 为 true） */
  routable: boolean;
}

export interface RelayRouteInput {
  /** 请求里的 model；没带为 null */
  requested: string | null;
  /** 运行中的托管模型名 */
  running: readonly string[];
  /** runtime 决议出的托管默认模型；没有模型在跑为 null */
  managedDefault: string | null;
  /** 该名字是否是面板里配置过的托管模型 */
  isConfiguredModel: (name: string) => boolean;
  /** 全部外部上游（含已停用的，点名停用的上游要给出明确错误） */
  upstreams: readonly RelayUpstream[];
  /** 用户显式设为默认的上游名；未设置为 null */
  defaultUpstream: string | null;
}

export type RelayTarget = { kind: "managed"; name: string } | { kind: "external"; name: string };

export type RelayRouteVia = "requested" | "default" | "fallback-default" | "fallback-unreachable";

export type RelayRouteDecision =
  | {
      kind: "route";
      target: RelayTarget;
      via: RelayRouteVia;
      /** 需要激活一次后台探测的上游名（默认上游不可达导致本次降级时）；否则 null */
      activate: string | null;
    }
  | { kind: "not-running"; model: string }
  | { kind: "upstream-disabled"; upstream: string }
  | { kind: "no-model" };

export interface RelayDefault {
  target: RelayTarget | null;
  /** 本该接收默认流量、但因不可达被跳过的上游名；没有降级为 null */
  degradedFrom: string | null;
}

/**
 * 决议生效的默认目标：
 * 1. 默认上游启用且可用 → 它
 * 2. 有托管默认模型 → 它（第 1 步是因为不可达被跳过时，记下 degradedFrom）
 * 3. 默认上游启用但不可达、又没有托管模型可降级 → 仍是它，让客户端看到真实错误
 * 4. 否则没有默认目标
 */
export function resolveRelayDefault(
  input: Pick<RelayRouteInput, "managedDefault" | "upstreams" | "defaultUpstream">,
): RelayDefault {
  const upstream =
    input.defaultUpstream !== null
      ? input.upstreams.find((u) => u.name === input.defaultUpstream && u.enabled)
      : undefined;

  if (upstream?.routable) return { target: { kind: "external", name: upstream.name }, degradedFrom: null };
  if (input.managedDefault !== null) {
    return { target: { kind: "managed", name: input.managedDefault }, degradedFrom: upstream?.name ?? null };
  }
  if (upstream !== undefined) return { target: { kind: "external", name: upstream.name }, degradedFrom: null };
  return { target: null, degradedFrom: null };
}

export function decideRelayRoute(input: RelayRouteInput): RelayRouteDecision {
  const { requested } = input;

  if (requested !== null) {
    if (input.running.includes(requested)) {
      return { kind: "route", target: { kind: "managed", name: requested }, via: "requested", activate: null };
    }
    const upstream = input.upstreams.find((u) => u.name === requested);
    if (upstream !== undefined) {
      return upstream.enabled
        ? { kind: "route", target: { kind: "external", name: requested }, via: "requested", activate: null }
        : { kind: "upstream-disabled", upstream: requested };
    }
    if (input.isConfiguredModel(requested)) return { kind: "not-running", model: requested };
  }

  const fallback = resolveRelayDefault(input);
  if (fallback.target === null) return { kind: "no-model" };

  const via: RelayRouteVia =
    fallback.degradedFrom !== null ? "fallback-unreachable" : requested === null ? "default" : "fallback-default";
  return { kind: "route", target: fallback.target, via, activate: fallback.degradedFrom };
}
```

```ts
/**
 * 转发到外部上游前的请求体改写（纯函数）。
 *
 * 面板对外的模型名是上游的登记名（如 strata），上游自己认的模型名往往是另一个
 * （如 Qwen3.8-Flash-…）。登记时填了 upstream_model，就在这里把请求体的 model 换成它；
 * 没填则原样透传，适用于上游不校验 model 字段的情况。
 */
export function applyUpstreamModel(rawBody: string, upstreamModel: string): string {
  let parsed: unknown;
  try {
    parsed = JSON.parse(rawBody);
  } catch {
    return rawBody;
  }
  if (typeof parsed !== "object" || parsed === null || Array.isArray(parsed)) return rawBody;
  return JSON.stringify({ ...(parsed as Record<string, unknown>), model: upstreamModel });
}
```

```ts
 * 在托管模型的聚合结果后追加外部上游条目。外部条目是面板自己合成的，不去请求上游：
 * 上游的 /v1/models 里列的是它自己认的模型名，而这里要给客户端的是面板的登记名。

 * 默认是外部上游的情况）。
 */
export function appendExternalModels(
  body: ModelsListBody,
  externalNames: readonly string[],
  defaultName: string | null,
): ModelsListBody {
  const data: Record<string, unknown>[] = [
    ...body.data,
    ...externalNames.map((id) => ({ id, object: "model", owned_by: "external" })),
  ];
  const index = data.findIndex((item) => item.id === defaultName);
  if (index > 0) data.unshift(...data.splice(index, 1));
  return { object: "list", data };
}
```

```ts
import { resolveRelayDefault, type RelayRouteInput, type RelayUpstream } from "../lib/relay-route";
import { isRoutable, type UpstreamHealth } from "../lib/upstream-health";
import { createModelRepo } from "./repo/models";
import { getDefaultUpstream, listUpstreams, type StoredUpstream } from "./repo/upstreams";
import type { RuntimeService, RuntimeStatus } from "./runtime";

/**
 * 路由上下文的 IO 装配：把 runtime 的运行状态、上游表、存活状态读到一起，
 * 交给 lib/relay-route.ts 的纯函数决议。中转 route 与默认模型、运行状态两个接口共用，
 * 保证三处看到的「生效默认」是同一个算法算出来的。
 */

/** 只依赖 snapshot，方便测试里用字面量对象替身 */
export interface HealthSource {
  snapshot(name: string): UpstreamHealth;
}

export interface RelayContext {
  status: RuntimeStatus;
  upstreams: StoredUpstream[];
  /** 与 upstreams 同序的路由视图（启用状态 + 是否可作为默认目标） */
  routes: RelayUpstream[];
  defaultUpstream: string | null;
}

export async function loadRelayContext(
  db: Database.Database,
  runtime: RuntimeService,
  health: HealthSource,
): Promise<RelayContext> {
  const status = await runtime.getRuntimeStatus();
  const upstreams = listUpstreams(db);
  return {
    status,
    upstreams,
    routes: upstreams.map((upstream) => ({
      name: upstream.name,
      enabled: upstream.enabled,
      routable: isRoutable(health.snapshot(upstream.name).state),
    })),
    defaultUpstream: getDefaultUpstream(db),
  };
}

export function routeInputOf(ctx: RelayContext, db: Database.Database, requested: string | null): RelayRouteInput {
  const repo = createModelRepo(db);
  return {
    requested,
    running: ctx.status.models.map((m) => m.model),
    managedDefault: ctx.status.defaultModel,
    isConfiguredModel: (name) => repo.getModel(name) !== null,
    upstreams: ctx.routes,
    defaultUpstream: ctx.defaultUpstream,
  };
}

export interface EffectiveDefault {
  name: string | null;
  kind: "managed" | "external" | null;
  /** 默认上游不可达、流量被临时改发到托管模型 */
  degraded: boolean;
}

export function effectiveDefault(ctx: RelayContext): EffectiveDefault {
  const resolved = resolveRelayDefault({
    managedDefault: ctx.status.defaultModel,
    upstreams: ctx.routes,
    defaultUpstream: ctx.defaultUpstream,
  });
  return {
    name: resolved.target?.name ?? null,
    kind: resolved.target?.kind ?? null,
    degraded: resolved.degradedFrom !== null,
  };
}
```

```ts
async function proxy(req: Request, ctx: { params: Promise<{ path?: string[] }> }): Promise<Response> {
  const auth = await requireAuth(req, getDb());
  if (auth instanceof Response) return auth;

  const db = getDb();
  const monitor = getUpstreamMonitor();
  const relay = await loadRelayContext(db, getRuntimeService(), monitor);
  const { status } = relay;
  const { path } = await ctx.params;
  const method = req.method.toUpperCase();

  if (method === "GET" && isModelsListPath(path)) {
    const managed = await buildAggregatedModelsList(status.models, status.defaultModel, {
      loadEffortContext: (model) => getEffortMappingContext(db, getPanelModelsRoot(), model),
    });
    // 列表的语义是「现在能用的」：停用与被判为不可达的上游不列出
    const externals = relay.routes.filter((u) => u.enabled && u.routable).map((u) => u.name);
    return NextResponse.json(appendExternalModels(managed, externals, effectiveDefault(relay).name));
  }

  const contentType = req.headers.get("content-type");
  let rawBody: string | undefined;
  if (method === "POST" && isJsonContentType(contentType)) {
    const bodyResult = await readBoundedBodyText(req.body, MAX_BODY_BYTES);
    if (!bodyResult.ok) return requestTooLarge(req);
    rawBody = bodyResult.text;
  }

  const requested =
    (rawBody !== undefined ? extractRequestedModel(rawBody) : null) ??
    requestedModelFromQuery(new URL(req.url).searchParams);
  const decision = decideRelayRoute(routeInputOf(relay, db, requested));
  if (decision.kind === "no-model") return fail(req, 503, { error: "没有运行中的模型", hint: "/models/profiles" });
  if (decision.kind === "not-running") return modelNotRunning(req, decision.model);
  if (decision.kind === "upstream-disabled") return upstreamDisabled(req, decision.upstream);

  // 默认上游不可达导致本次降级：后台激活一次探测（限频），不等它
  if (decision.activate !== null) monitor.activate(decision.activate);

  if (decision.target.kind === "external") {
    const name = decision.target.name;
    const upstream = relay.upstreams.find((u) => u.name === name);
    if (upstream === undefined) return fail(req, 503, { error: "外部上游配置缺失" });

    const body =
      rawBody !== undefined && upstream.upstreamModel !== null
        ? applyUpstreamModel(rawBody, upstream.upstreamModel)
        : rawBody;
    const { url, init } = buildProxyRequest(req, upstream.baseUrl, path, body);
    // buildProxyRequest 已剥掉客户端带来的面板凭证，这里换成上游自己的密钥
    if (upstream.apiKey !== null) (init.headers as Headers).set("authorization", `Bearer ${upstream.apiKey}`);

    let response: Response;
    try {
      response = await fetch(url, init);
    } catch (error) {
      // 客户端自己断开也会让 fetch 抛错，那不是上游的问题，不计入失败
      if (!req.signal.aborted) monitor.report(name, false, error instanceof Error ? error.message : String(error));
      return fail(req, 502, { error: "上游不可达" });
    }
    monitor.report(name, true);
    const sanitized = sanitizeUpstreamResponse(response);
    sanitized.headers.set("x-llamapad-model", name);
    sanitized.headers.set("x-llamapad-model-route", decision.via);
    return sanitized;
  }

  const model = decision.target.name;
  const target = status.models.find((m) => m.model === model);
  if (target === undefined || target.hostPort === null) {
    return fail(req, 503, { error: "运行中模型的端口未知（模型配置缺失）", hint: "/models/profiles" });

  let overrideBody = rawBody;
```

```ts
 * 外部上游：不由面板启停、但可经中转入口访问的 OpenAI 兼容服务。
 *
 * - GET  /api/v1/upstreams → `{ upstreams: UpstreamView[] }`，按 name 排序。密钥只回尾 4 位
 * - POST /api/v1/upstreams → 201 UpstreamView。
 *   body `{ name, displayName, baseUrl, apiKey?, upstreamModel?, enabled?, note? }`
 *
 * 失败：400（校验失败，`issues` 指出字段）/ 409（与已有上游或模型配置重名）。
 *
 * 不调自动快照：外部上游不进 YAML 导出（导出文件不含凭据）。

  name: z.string().min(1),
  displayName: z.string().min(1),
  baseUrl: z.string().min(1),
  apiKey: z.string().nullable().optional(),
  upstreamModel: z.string().nullable().optional(),
  enabled: z.boolean().optional(),
  note: z.string().nullable().optional(),
});

export async function GET(req: Request): Promise<Response> {
  const auth = await requireAuth(req, getDb());
  if (auth instanceof Response) return auth;

  const db = getDb();
  const monitor = getUpstreamMonitor();
  const defaultUpstream = getDefaultUpstream(db);
  return NextResponse.json({
    upstreams: listUpstreams(db).map((stored) => toUpstreamView(stored, monitor.snapshot(stored.name), defaultUpstream)),
  });
}

export async function POST(req: Request): Promise<Response> {
  const auth = await requireAuth(req, getDb());
  if (auth instanceof Response) return auth;

  const parsed = createBody.safeParse(await req.json().catch(() => null));
  if (!parsed.success) {
    return NextResponse.json(
      {
        error: "invalid_body",
        issues: parsed.error.issues.map((issue) => ({ path: issue.path.join("."), message: issue.message })),
      },
      { status: 400 },
    );
  }

  const db = getDb();
  try {
    const created = createUpstream(db, parsed.data);
    const monitor = getUpstreamMonitor();
    // 新登记的上游立刻探测一次，不让它在列表里顶着「未知」等到下一个 15 秒
    monitor.activate(created.name);
    return NextResponse.json(toUpstreamView(created, monitor.snapshot(created.name), getDefaultUpstream(db)), {
      status: 201,
    });
  } catch (error) {
    if (error instanceof UpstreamError) {
      return NextResponse.json(
        { error: error.message, issues: error.field ? [{ path: error.field, message: error.message }] : [] },
        { status: upstreamErrorStatus(error.code) },
      );
    }
    throw error;
  }
```

```ts
} from "@/server/repo/upstreams";
import { toUpstreamView } from "@/server/upstreams/view";

export const runtime = "nodejs";
export const dynamic = "force-dynamic";

/**
 * - GET    /api/v1/upstreams/:name → UpstreamView（404 不存在）
 * - PUT    /api/v1/upstreams/:name → UpstreamView。body 的字段都可选，缺席表示不改；
 *   `apiKey` 传空串或 null 表示清除密钥。name 不可改（它是客户端写死的模型名）
 * - DELETE /api/v1/upstreams/:name → 204。删的是默认上游时一并清除默认
 */
const updateBody = z.strictObject({
  displayName: z.string().optional(),
  baseUrl: z.string().optional(),
  apiKey: z.string().nullable().optional(),
  upstreamModel: z.string().nullable().optional(),
  enabled: z.boolean().optional(),
  note: z.string().nullable().optional(),
});

type Ctx = { params: Promise<{ name: string }> };

function errorResponse(error: unknown): Response {
  if (error instanceof UpstreamError) {
    return NextResponse.json(
      { error: error.message, issues: error.field ? [{ path: error.field, message: error.message }] : [] },
      { status: upstreamErrorStatus(error.code) },
    );
  }
  throw error;
}

export async function GET(req: Request, ctx: Ctx): Promise<Response> {
  const auth = await requireAuth(req, getDb());
  if (auth instanceof Response) return auth;

  const db = getDb();
  const { name } = await ctx.params;
  const stored = getUpstream(db, name);
  if (stored === null) return NextResponse.json({ error: `上游不存在: ${name}` }, { status: 404 });
  return NextResponse.json(toUpstreamView(stored, getUpstreamMonitor().snapshot(name), getDefaultUpstream(db)));
}

export async function PUT(req: Request, ctx: Ctx): Promise<Response> {
  const auth = await requireAuth(req, getDb());
  if (auth instanceof Response) return auth;

  const parsed = updateBody.safeParse(await req.json().catch(() => null));
  if (!parsed.success) {
    return NextResponse.json(
      {
        error: "invalid_body",
        issues: parsed.error.issues.map((issue) => ({ path: issue.path.join("."), message: issue.message })),
      },
      { status: 400 },
    );
  }

  const db = getDb();
  const { name } = await ctx.params;
  try {
    const updated = updateUpstream(db, name, parsed.data);
    const monitor = getUpstreamMonitor();
    // 地址、密钥或启用状态可能变了：重新探测一次，让列表上的状态对应新配置
    monitor.activate(name);
    return NextResponse.json(toUpstreamView(updated, monitor.snapshot(name), getDefaultUpstream(db)));
  } catch (error) {
    return errorResponse(error);
  }
}

export async function DELETE(req: Request, ctx: Ctx): Promise<Response> {
  const auth = await requireAuth(req, getDb());
  if (auth instanceof Response) return auth;

  const { name } = await ctx.params;
  try {
    deleteUpstream(getDb(), name);
    return new Response(null, { status: 204 });
  } catch (error) {
    return errorResponse(error);
  }
}
```

```ts
import type { UpstreamView } from "./upstream-types";
import { normalizeUpstreamBaseUrl, upstreamNameProblem } from "./upstream-url";

/**
 * 外部上游表单的草稿与请求体构造（纯函数，弹窗组件只负责渲染与发请求）。
 *
 * 密钥在编辑时的三种意图要分清：输入框留空 = 不改（服务端也不会把已保存的明文发回来）；
 * 输入了新值 = 替换；勾了「清除密钥」= 清除。
 */

export interface UpstreamDraft {
  name: string;
  displayName: string;
  baseUrl: string;
  /** 新建时是要保存的密钥；编辑时是「新密钥」，留空表示不改 */
  apiKey: string;
  /** 仅编辑时有意义 */
  clearApiKey: boolean;
  upstreamModel: string;
  note: string;
}

export type DraftMode = "create" | "edit";

export function emptyDraft(): UpstreamDraft {
  return { name: "", displayName: "", baseUrl: "", apiKey: "", clearApiKey: false, upstreamModel: "", note: "" };
}

export function draftFromView(view: UpstreamView): UpstreamDraft {
  return {
    name: view.name,
    displayName: view.displayName,
    baseUrl: view.baseUrl,
    apiKey: "",
    clearApiKey: false,
    upstreamModel: view.upstreamModel ?? "",
    note: view.note ?? "",
  };
}

export type DraftProblem = "name" | "nameReserved" | "displayName" | "baseUrl";

/** 第一个有问题的字段；都合法返回 null。服务端仍会再校验一遍，这里只为了即时提示 */
export function draftProblem(draft: UpstreamDraft, mode: DraftMode): DraftProblem | null {
  if (mode === "create") {
    const problem = upstreamNameProblem(draft.name);
    if (problem === "format") return "name";
    if (problem === "reserved") return "nameReserved";
  }
  if (draft.displayName.trim() === "") return "displayName";
  if (!normalizeUpstreamBaseUrl(draft.baseUrl).ok) return "baseUrl";
  return null;
}

export function buildCreateBody(draft: UpstreamDraft): Record<string, string> {
  const body: Record<string, string> = {
    name: draft.name,
    displayName: draft.displayName.trim(),
    baseUrl: draft.baseUrl.trim(),
  };
  if (draft.apiKey.trim() !== "") body.apiKey = draft.apiKey.trim();
  if (draft.upstreamModel.trim() !== "") body.upstreamModel = draft.upstreamModel.trim();
  if (draft.note.trim() !== "") body.note = draft.note.trim();
  return body;
}

export function buildUpdateBody(draft: UpstreamDraft): Record<string, string | null> {
  const body: Record<string, string | null> = {
    displayName: draft.displayName.trim(),
    baseUrl: draft.baseUrl.trim(),
    upstreamModel: draft.upstreamModel.trim() === "" ? null : draft.upstreamModel.trim(),
    note: draft.note.trim() === "" ? null : draft.note.trim(),
  };
  if (draft.clearApiKey) body.apiKey = "";
  else if (draft.apiKey.trim() !== "") body.apiKey = draft.apiKey.trim();
  return body;
}

/** POST /api/v1/upstreams/test 的请求体（保存前验证） */
export function buildTestBody(draft: UpstreamDraft, mode: DraftMode): Record<string, string | null> {
  const baseUrl = draft.baseUrl.trim();
  if (draft.apiKey.trim() !== "") return { baseUrl, apiKey: draft.apiKey.trim() };
  if (mode === "edit" && !draft.clearApiKey) return { baseUrl, name: draft.name };
  return { baseUrl, apiKey: null };
}
```

```tsx
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ enabled }),

    else toast.info(t("testStatus", { status: probe.status ?? 0 }));
    await reload();

    const res = await run(`delete:${deleting.name}`, () =>
      apiFetch(`/api/v1/upstreams/${deleting.name}`, { method: "DELETE" }),
    );
    if (res === null) return;
    setDeleting(null);
    await afterChange();

  return (

        </div>

            <TableHeader>
              <TableRow>
                <TableHead>{t("colName")}</TableHead>
                <TableHead>{t("colUrl")}</TableHead>
                <TableHead>{t("colKey")}</TableHead>
                <TableHead>{t("colState")}</TableHead>
                <TableHead>{t("colEnabled")}</TableHead>
                <TableHead />
              </TableRow>
            </TableHeader>

                    </TableCell>
                    <TableCell>
```

````markdown
## 外部上游

面板除了中转自己启动的 llama.cpp 模型，也能中转已经部署在别处的 OpenAI 兼容服务，
例如另一台机器上的推理引擎。这类服务叫外部上游：面板不负责它的启停，只负责把请求转过去。

### 登记

在「API 中转」页的「外部上游」区域点「添加上游」：

| 字段 | 说明 |
| --- | --- |
| 名称 | 请求时填在 `model` 字段里的名字，保存后不能修改。不能与已有的模型配置重名 |
| 上游地址 | 填到 `/v1` 之前，例如 `http://192.168.1.10:8080`。只支持 `http` 与 `https` |
| API 密钥 | 上游需要鉴权时填写。面板转发时把它放进 `Authorization: Bearer` 头 |
| 上游模型名 | 填了就在转发时把请求里的 `model` 换成它；上游不校验 `model` 可以留空 |

保存前可以点「测试连接」。面板会请求上游的 `/v1/models`，并列出它返回的模型名，点一下就能填进「上游模型名」。

### 请求

和请求托管模型一样，把登记的名称写进 `model`：

```bash
curl http://<服务器地址>:28960/llama-proxy/v1/chat/completions \
  -H "Authorization: Bearer lp_xxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"model":"strata","messages":[{"role":"user","content":"你好"}]}'
```

请求头里带的是面板的 Token，不是上游的密钥。路径原样转发，上游支持的其他兼容接口
（如 `/v1/messages`、`/v1/responses`）同样可用。`GET /v1/models` 的结果里会包含启用且可达的外部上游。

发往外部上游的请求不做思考强度映射，`reasoning_effort` 原样传给上游。

### 设为默认

外部上游可以设为默认模型。这个选择会保存下来，面板重启后仍然有效，之后启动托管模型也不会改变它。
把默认改回某个托管模型、停用或删除该上游，都会让默认回到原来的规则（最早启动的托管模型）。

### 存活状态

| 状态 | 含义 |
| --- | --- |
| 未知 | 面板刚启动或刚登记，还没探测过。请求照常转发 |
| 可达 | 能连上。面板每 15 秒探测一次 |
| 不可达 | 连续 3 次连不上。面板停止定时探测 |
| 已停用 | 开关关闭，请求它会返回错误 |

只要上游返回了 HTTP 响应就算可达，包括 401 和 500：密钥填错不会让它变成不可达。

不可达的上游不再被定时探测，以下情况会重新检查一次：有请求点名它、有本该由它接收的默认请求、
有人打开「API 中转」页、有人点「测试连接」。

默认上游不可达时：

- 有托管模型在跑：不带 `model` 的请求临时改发到托管模型，响应头
  `x-llamapad-model-route` 为 `fallback-unreachable`。上游恢复后自动切回，
  恢复后的第一个请求仍会落在托管模型上。
- 没有托管模型在跑：请求照常发往上游，客户端收到 502。

在 `model` 里点名了某个上游的请求永远发往它，不会被改发。

启动很慢的服务在加载期间会被判为不可达。如果不希望这段时间的默认请求落到托管模型上，
就不要把它设为默认，让客户端显式写明 `model`。

### 限制

- Chat 页不能选择外部上游。
- 外部上游没有监控曲线，也不参与显存检查。
- 外部上游的配置不在配置导出里，备份请备份 `panel.db`。
````
