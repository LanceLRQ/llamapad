# 模型下载

## 三种来源

「下载」页新建下载时分两个入口：

- **HF 仓库**：填 Hugging Face 仓库 ID（`owner/repo`），面板会登记一份「仓库档案」并读取远端文件清单，按量化自动分组，你选一组（或多组）提交后才真正入队下载
- **URL 直链**：直接填一个 http/https 链接，不经过仓库档案这一层，落盘文件名默认取链接末段（可手动指定）。落盘目录不能选在任何已登记的仓库档案目录里——那些目录由档案独占管理，混进自由下载的文件会让「这个量化下过没有」的判定失真，选了会被直接拒绝

仓库档案与 URL 直链是两条独立路径：URL 直链更适合下载单个文件或非 Hugging Face 源；仓库档案的价值在于它把整个仓库的量化清单、本地下载状态（未下载 / 部分分片 / 已下载 / 文件在别处）都记录下来，方便同一个仓库后续继续挑其他量化下载，档案管理见[文件与命名空间](./files.md)。

## 自动分组：量化、分片、mmproj

仓库档案页展示远端文件清单时，面板会按下面的规则自动分组，而不是把几十个 GGUF 文件平铺展示：

- 从文件名识别量化标签（`Q4_K_M`、`Q8_0`、`IQ4_XS`、`BF16` 等），不同量化各自成一组，绝不混组
- 文件名带 `-00001-of-00005.gguf` 这类分片命名的，同前缀、同声明总数的文件自动归并为一组——选中一个分片会带出整组，因为分片模型的 GGUF 引用是一份 glob 而不是单个路径，只下载一半分片模型是起不来的
- 文件名以 `mmproj` 开头的文件识别为多模态投影文件，即便与某个量化组同名同款，也单独成组、不与模型主体混在一起
- 只有 `.gguf` 后缀的文件参与分组，仓库里的 `safetensors` / `.bin` / `README` 等一律跳过不展示

## 断点续传与 sha256 校验

下载支持 HTTP Range 续传：暂停、网络中断、或面板重启后恢复的任务，都会从已下载的 `.part` 临时文件末尾继续，而不是重新下载整个文件。

sha256 校验只在**能拿到期望哈希值**时才会做：HF 仓库下载的文件如果在 LFS 元数据里带了 oid，面板会边下边算实际哈希，下载完成时与期望值比对；URL 直链下载通常没有可比对的哈希来源，会跳过校验。比对不通过时任务会被标记失败，错误信息里带着期望值与实际值，需要手动重试（不会自动重下）。

## 暂停 / 继续 / 取消 / 重试的区别

四个操作看起来相似，语义并不相同：

| 操作 | 效果 | `.part` 临时文件 |
| --- | --- | --- |
| 暂停 | 中断当前传输，队列停在这个任务上 | 保留，供继续时接着下 |
| 继续 | 恢复一个已暂停的任务 | 按 Range 续传 |
| 取消 | 彻底放弃这个任务 | 删除 |
| 重试 | 让一个「失败」或「已取消」的任务原地回到排队状态 | 若存在则续传，不存在则从头下 |

重试只对失败或已取消的任务开放，对完成的任务重试没有意义（要再下一遍应该重新入队），对暂停的任务应该用「继续」而不是「重试」——状态不匹配时接口会返回 409。

下载队列本身是单并发顺序执行：一次只跑一个任务，跑完（或被跳过）自动接上下一个。队列连续失败达到 3 次后会自动停止，不再自动接棒。偶发的单文件 404 或哈希不符不该拖垮整批任务，所以未达到这个次数时失败了也会继续跑下一个；但连续失败到 3 次，大概率是断网或磁盘写满一类系统性故障，继续空转没有意义。面板会停队并在下载页顶部提示，需要处理完失败任务后手动点「继续队列」才会重新开始。顺带一提，这条「队列已停止」的提示是按「有任务在排队、却没有任何一个在下载」这个现象判定的，所以你手动暂停当前下载、而队列里还有别的任务在等时，同一条提示也会出现——那种情况下一次失败都没发生，点「继续队列」或恢复被暂停的任务即可。新入队的任务只会排队，不会自动唤醒已经停摆的队列，避免停一次后每次只能挤进去一个任务又停。

## Token、镜像与代理配置

三项都在「设置 → 模型库 → 下载源」：

- **访问令牌（Token）**：环境变量 `HF_TOKEN` 优先于面板保存的令牌。设了这个环境变量后，面板内的 Token 输入框会变成只读展示；要改用面板保存的令牌，需要先清除环境变量并重启容器
- **镜像源**：官方（`huggingface.co`）、预设的国内镜像（`hf-mirror.com`），或自定义 URL，三选一
- **出站代理**：面板设置里保存的代理会覆盖 `panel.yaml` 里配置的代理，保存后立即生效，不需要重启容器。`panel.yaml` 本身不会被面板改写，面板起不来时仍然可以直接编辑这份文件做人工诊断。代理地址如果带了用户名密码，展示时会自动遮蔽成 `***`，不回显明文

保存 Token / 镜像 / 代理后，设置页有一个「测试连接」按钮，会按当前生效的组合配置向 Hugging Face 的 whoami 接口发一次真实请求，用来验证连通性与令牌有效性（未配置 Token 时只验证匿名连通），改完配置建议先测一次再去下载页排队，比排到一半才发现连不通更省时间。
